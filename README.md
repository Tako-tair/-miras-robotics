# Miras 2.8: сайт команды FIRST® LEGO® League

Сайт команды **Miras 2.8** (Алматы), сезон BIOGLOW™ 2026/27.
Инновационный проект «Воздух над Алматы»: робот, который измеряет смог PM2.5, решает, как сильно фильтровать, и очищает воздух.

🌐 **Сайт:** https://tako-tair.github.io/-miras-robotics/

## Что есть на сайте
- 3 языка: English, Русский, Қазақша.
- Живые данные о воздухе Алматы (Open-Meteo, модель CAMS) с графиком за 4 дня.
- Симулятор очистки воздуха: 4 способа (наш фильтр, электростатика, стена из мха, водяной туман).
- Проблема смога и биоразнообразие (BIOGLOW), инженерный процесс, бюджет прототипа.
- Викторина, QR-код для стенда, сводка проекта в PDF для судей, режим стенда.
- Работа без интернета (после первого открытия) и установка как приложения.
- **MIRAS Beast** — командная зона с блочным программированием и симулятором FLL, закрыта паролем.

## Как обновить сайт
Замените нужный файл в репозитории (кнопка **Add file → Upload files**) и нажмите **Commit**. Через 1–2 минуты GitHub Pages опубликует новую версию.
После каждого обновления поменяйте номер версии в первой строке кода `sw.js` (например `miras28-v19` → `miras28-v20`), чтобы телефоны посетителей подхватили новую версию.

### Настройки (в `index.html`, блок «НАСТРОЙКИ САЙТА» в начале скрипта)
- `SPONSOR` — спонсор на главном экране (название, логотип, сайт).
- `NEXT_EVENT` — обратный отсчёт до турнира: `{name:"Almaty Regional",date:"2027-02-14"}`.
- `TEAM_NUMBER` — официальный номер команды FLL.
- `FEEDBACK_URL` — адрес формы Formspree, чтобы отзывы приходили на почту.
- `BUDGET` — цены деталей прототипа (сейчас примерные).

## Командная зона (MIRAS Beast)
- Кнопка **MIRAS Beast** в верхнем меню (и замок в шапке) ведёт на `team.html`.
- После верного пароля — приветствие с логотипом, затем открывается Beast: Bluetooth к хабу SPIKE Prime и сохранение проектов работают.
- Пароль знают участники команды и тренеры. **Не пишите пароль в этом репозитории, в README и в комментариях: репозиторий публичный.**

### Новая версия Beast или смена пароля
1. Откройте `tools/lock-tool.html` (на сайте или скачав файл к себе).
2. Выберите **исходный** файл Beast, введите пароль, нажмите «Зашифровать и скачать».
3. Загрузите полученный `team.html` в репозиторий вместо старого.

⚠️ **Никогда не загружайте в этот репозиторий исходный (незашифрованный) файл Beast:** репозиторий виден всем.

## Безопасность
- Beast зашифрован: AES-256-GCM, ключ из пароля через PBKDF2-SHA256 с 600 000 повторами. Без пароля код не прочитать даже из исходника. После 5 неверных попыток вход делает паузу.
- Политика безопасности контента (CSP): сайт не загружает чужие скрипты и связывается только с Open-Meteo и Formspree.
- Тексты из формы и с сервисов выводятся как обычный текст. В форме отзывов есть ловушка для спам-ботов.
- Главное — защитить **аккаунт GitHub**: включите двухфакторную защиту (Settings → Password and authentication), не давайте доступ на запись посторонним.
