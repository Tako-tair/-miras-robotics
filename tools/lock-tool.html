🔒 Замок для командной зоны

Эта страница шифрует MIRAS 2.8 Beast вашим паролем и создаёт файл team.html для сайта. Всё происходит только на этом компьютере: страница ничего не отправляет в интернет (это запрещено её настройками безопасности).

1Выберите файл Beast

Нужен обычный (незашифрованный) файл, например MIRAS_2.8_Beast_3.html.

2Придумайте пароль команды

  • Минимум 12 символов. Лучше 4–5 случайных слов, например яблоко-ракета-гора-синий-47.
  • Не используйте название команды, дни рождения и пароли от других сайтов.
  • Сообщайте пароль только лично участникам и тренерам, не пишите его в общих чатах.

3Зашифровать и скачать

  • Положите скачанный team.html в папку сайта вместо старого и загрузите сайт заново.
  • Никогда не загружайте на сайт и в GitHub исходный файл Beast, только зашифрованный team.html.
  • Сменили пароль — старый сразу перестанет работать для новой версии сайта.
